DEPENDENCIES AND COST

UI: HTML, CSS, JavaScript; no UI framework. Static preview/tests: Node built-ins.
Notes: @mlc-ai/web-llm 0.2.85 from https://esm.run/@mlc-ai/web-llm@0.2.85. Qwen3.5-9B q4f16_1-MLC, or q4f32_1-MLC without shader-f16. Browser GPU inference, context 16384. Two full-transcript calls: a bounded internal reasoning pass (1400 output tokens, temperature 0.7, top_p 0.8, presence_penalty 1.5, enable_thinking=true), then a source-checked structured extraction (2400 output tokens, temperature 0.1, top_p 0.8, presence_penalty 0, enable_thinking=false). Final categories: actions, decisions, schedules and open questions. Internal reasoning is never displayed/exported and may end at its token allowance; the next pass reads the whole source independently. Incomplete final notes or invalid source references fail visibly. Original source evidence is retrieved verbatim. Owners/deadlines are checked against cited text; article-only deadline differences are preserved. Valid citations and a model review do not prove semantic accuracy. Note generation has no elapsed-time cutoff; the user can cancel. A live elapsed timer runs during inference. No weight training. About 5 GB initial download, reused from IndexedDB. See note-quality-v3-results.json for actual development results.
Audio: Python 3.12 recommended; faster-whisper 1.2.1, sherpa-onnx 1.13.8, CTranslate2 4.8.3, PyAV 16.0.1. Primary versions are pinned in local-audio/requirements.txt. Transitive dependencies are resolved by pip; this is not a fully locked environment. PyAV bundles FFmpeg libraries. CPU int8 Whisper small.en (default) or base.en (faster), beam size 5, with a short construction glossary and optional user-supplied spelling hints, pyannote segmentation 3.0 ONNX and NeMo TitaNet small ONNX. No paid inference or Hugging Face token is required. Packaged Windows x64 and Mac Apple-silicon audio smoke tests run in CI; see release test reports.
Model downloads: public Hugging Face model repositories and official sherpa-onnx GitHub releases. Models are fetched at first use and not distributed in this project ZIP. Faster-whisper and pyannote segmentation use MIT licenses; sherpa-onnx, CTranslate2 and Qwen3.5-9B use Apache-2.0; PyAV uses BSD-3-Clause, with separate bundled codec licenses; NeMo TitaNet Small's upstream NVIDIA model card refers to the NeMo Toolkit license (https://catalog.ngc.nvidia.com/orgs/nvidia/nemo/models/titanet_small). Retain upstream notices. The downloaded segmentation archive includes its license.
No API keys, OpenAI account integration, hosted inference or cloud storage. HF implicit-token use and HF telemetry are disabled by this app. Local compute, storage, and first-time downloads are still required. No runtime cost is charged by this project.

SYNTHETIC DATA JUSTIFICATION

No private recordings or meeting excerpts are distributed with this project. Fictional text scenarios reflect the thesis's flooring-repair coordination setting without representing real Evergreen conversations. scripts/generate-data.cjs regenerates text and starter reference annotations. Those references were authored with Codex assistance; independent review is required before formal evaluation.
The included synthetic-introduction.wav uses an installed Windows offline speech voice and the fictional script in scripts/generate-audio-sample.ps1. It tests audio ingestion, an explicit name/role introduction, and the transcript-to-notes workflow. It is one synthetic voice, so it is not evidence of real-meeting diarization accuracy. Exact synthesis varies with installed voice. Development also used the official sherpa-onnx two-speaker English sample (2-two-speakers-en.wav); that third-party recording is not redistributed here.
