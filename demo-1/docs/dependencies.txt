DEPENDENCIES AND COST

UI: HTML, CSS, JavaScript; no UI framework. Static preview/tests: Node built-ins.
Notes: @mlc-ai/web-llm 0.2.85 from https://esm.run/@mlc-ai/web-llm@0.2.85. Qwen3-8B q4f16_1-MLC, or q4f32_1-MLC if shader-f16 is unavailable. Local browser GPU inference, temperature 0.3, top_p 0.8, presence_penalty 0, context 16384, maximum 3000 output tokens per pass. Uses the model's supported non-thinking mode through extra_body.enable_thinking=false and JSON schemas. One pass checks each potential follow-up against the full meeting; another reads the full meeting for decisions/restrictions and unresolved issues. Fictional worked examples illustrate empty results, withdrawn proposals, uncertainty, and follow-up work. note-engine.js contains the prompts, candidate identification, inference configuration and exact-source-quote matching. Conservative checks reject obvious status reports mislabeled as decisions and resolved statements mislabeled as questions; repeated actions with overlapping sources and matching owner/wording keep the version citing later evidence. core.js validates owner/deadline presence in cited evidence, leaves conditional triggers out of fixed deadline fields, removes an unsupported self-recipient from a promise to contact "you", and preserves all source references in exports. Neither module proves semantic correctness. Model weights are unchanged. About 5 GB downloads on first use; later loads reuse saved files. See note-quality-results.json for measured development examples and limitations.
Audio: Python 3.12 recommended; faster-whisper 1.2.1, sherpa-onnx 1.13.8, CTranslate2 4.8.3, PyAV 16.0.1. Primary versions are pinned in local-audio/requirements.txt. Transitive dependencies are resolved by pip; this is not a fully locked environment. PyAV bundles FFmpeg libraries. CPU int8 Whisper base.en (optional small.en), pyannote segmentation 3.0 ONNX and NeMo TitaNet small ONNX. No paid inference or Hugging Face token is required. Packaged Windows x64 and Mac Apple-silicon audio smoke tests run in CI; see release test reports.
Model downloads: public Hugging Face model repositories and official sherpa-onnx GitHub releases. Models are fetched at first use and not distributed in this project ZIP. Faster-whisper and pyannote segmentation use MIT licenses; sherpa-onnx, CTranslate2 and Qwen3-8B use Apache-2.0; PyAV uses BSD-3-Clause, with separate bundled codec licenses; NeMo TitaNet Small's upstream NVIDIA model card refers to the NeMo Toolkit license (https://catalog.ngc.nvidia.com/orgs/nvidia/nemo/models/titanet_small). Retain upstream notices. The downloaded segmentation archive includes its license.
No API keys, OpenAI account integration, hosted inference or cloud storage. HF implicit-token use and HF telemetry are disabled by this app. Local compute, storage, and first-time downloads are still required. No runtime cost is charged by this project.

SYNTHETIC DATA JUSTIFICATION

No private recordings or meeting excerpts are distributed with this project. Fictional text scenarios reflect the thesis's flooring-repair coordination setting without representing real Evergreen conversations. scripts/generate-data.cjs regenerates text and starter reference annotations. Those references were authored with Codex assistance; independent review is required before formal evaluation.
The included synthetic-introduction.wav uses an installed Windows offline speech voice and the fictional script in scripts/generate-audio-sample.ps1. It tests audio ingestion, an explicit name/role introduction, and the transcript-to-notes workflow. It is one synthetic voice, so it is not evidence of real-meeting diarization accuracy. Exact synthesis varies with installed voice. Development also used the official sherpa-onnx two-speaker English sample (2-two-speakers-en.wav); that third-party recording is not redistributed here.
