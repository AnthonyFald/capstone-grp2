Demo 1 now offers the same installed local model as Demo 2. In this workspace, use Open Demo 1.cmd from the Capstone folder. Open http://127.0.0.1:4177/demo-1/, choose a transcript, and generate notes.

On another computer, follow the local runtime instructions to install Qwen 3.5 27B and start the shared companion. The browser 9B option remains available explicitly in the processing-method menu.

The 27B model uses roughly 17 GB of model files plus working memory. On the 16 GB RTX 5080, part of the workload uses system RAM. Parameter count alone does not prove quality or speed. Keep the page open while the elapsed timer runs; Cancel stops the request.
