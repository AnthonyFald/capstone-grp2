Windows · Apple silicon Mac · Process a recording · Help opening the app

Windows x64

  1. Download and extract. In Downloads, right-click Evergreen-Meeting-Demo-Windows.zip → Extract All… → Extract.
  2. Open the extracted folder. Double-click Evergreen Meeting Demo.exe. Windows may hide .exe. Keep the _internal folder beside the app.
  3. Keep the small companion window open. The browser opens automatically. Use Open demo to reopen the page later.

Mac with Apple silicon

For M1, M2, M3 and later M-series Macs. Check Apple menu → About This Mac → Chip. This download does not support Intel Macs.

  1. Download and unzip. In Finder → Downloads, double-click Evergreen-Meeting-Demo-Mac-Apple-Silicon.zip. Your browser may already have unzipped it.
  2. Move the app to Applications. Drag Evergreen Meeting Demo.app into Applications, then double-click it.
  3. Approve the first opening if macOS asks. See below. Keep the companion window open while using the browser page.

Process your recording

  1. Use the browser page opened by the app. Expand Start from a recording and look for Local audio companion connected.
  2. Choose an English MP3, WAV, M4A, OGG, or FLAC. Limits: 10 minutes and 80 MB. Set the number of speakers if you know it.
  3. Start with Whisper Base · faster and click Transcribe & separate speakers. First use downloads roughly 200 MB of audio models. The percentage and estimated countdown update while it works. Audio completed in… shows the total through the finished transcript, including model setup when needed.
  4. Review the words, speaker names and roles. Click a timestamp to listen. Introductions can suggest names, but every label can be corrected.
  5. Click Use reviewed transcript for notes, then Load AI & generate notes. The first Qwen download is roughly 1 GB. Loading and generation happen in sequence. Notes completed in… shows the total; automatic model setup is listed separately.
  6. Review and correct decisions, action items, owners, deadlines and open questions. Export notes .txt saves readable sections. Export speaker transcript .json saves the transcript for later.
  7. Click Quit in the companion when finished. Export first: transcripts and notes are not saved automatically.

Audio uses the CPU; AI notes need browser WebGPU support. Speaker labels and words can be wrong, especially with noise or overlapping voices. Introductions suggest names; they do not verify identity.

Help opening the app

First-open security approval: these free student builds are not developer-signed or notarized. Download only from this project's release. On Windows, if SmartScreen shows an unrecognized-app notice, check the file came from this page and use More info → Run anyway if available. If your organization blocks it, contact its administrator.

On Mac, first try opening the app. If macOS blocks the unrecognized developer, open System Settings → Privacy & Security, find Evergreen Meeting Demo, and click Open Anyway, then confirm. See Apple's instructions. Keep system security enabled. If macOS reports malware, do not override that warning.

Missing files: extract the complete Windows ZIP before opening the app. Moving only the .exe loses its tools. Mac users should move the whole .app into Applications.

Still seeing download buttons: use Open demo in the companion and keep it open. The public website supplies downloads; the local page connects to the tools on your computer.

No AI notes: use Chrome or Edge with WebGPU and internet for the first model download. Interrupted downloads retry. Your transcript stays in place if loading fails.

Another error: click Show support log in the companion. Close an older companion before opening a new one. Export current work before closing.

Your files stay local

Models are saved in your user account's Evergreen Meeting Demo folder: under Local App Data on Windows, or Library / Application Support on Mac. Temporary recording copies are deleted after processing; your original is untouched. A forced shutdown can leave a temporary copy. The latest transcript stays in memory until the companion stops.

To share a transcript, export its JSON and give it to a teammate. They can import it on the hosted Demo 1 page and generate notes without installing the companion.
