Download once. Process locally.

The audio companion turns a recording into a transcript with speaker labels, then opens the same Demo 1 interface for meeting notes. Anyone can download it here; no GitHub account or Codex installation is needed.

Download audio companion (.zip)

The ZIP contains the complete capstone project and both launchers. Free packages and models download during setup and first use. No paid API, key, or AI account. Recordings are processed on your computer.

Windows instructions · Mac instructions · Choose your recording

Windows

  1. Download and extract. Click the download button above. In File Explorer → Downloads, right-click capstone-grp2-main.zip, choose Extract All…, then Extract.
  2. Install Python 3.12 if needed. On the official Python 3.12 installer page, scroll to Files and choose Windows installer (64-bit). Open it, check Add python.exe to PATH, and install. Skip this step if Python 3.12 is already installed.
  3. Find the launcher. Open the extracted capstone-grp2-main folder, then demo-1. If you first see another capstone-grp2-main folder, open that too. Make sure you are in the extracted folder, not browsing inside the ZIP.
  4. Double-click Start Audio Demo.cmd. Windows may hide the .cmd extension and show it as “Start Audio Demo,” with type “Windows Command Script.”
  5. Keep the terminal window open. It installs the tools and opens the local demo. First setup can take several minutes. Use Chrome or Edge for the meeting-note AI.

Mac

  1. Download and extract. Click the download button above. In Finder → Downloads, double-click capstone-grp2-main.zip. If your browser already extracted it, open the resulting folder.
  2. Install Python 3.12 if needed. On the official Python 3.12 installer page, choose macOS 64-bit universal2 installer and follow the installer. This installer supports Intel and Apple Silicon Macs.
  3. Find the launcher. In Finder, open capstone-grp2-main → demo-1. Find Start Audio Demo.command.
  4. Open Terminal. Press Command + Space, type Terminal, and press Return. Type bash followed by one space. Drag Start Audio Demo.command from Finder into the Terminal window, then press Return. Dragging fills in the correct path for your Mac.
  5. Keep Terminal open. It installs the tools and opens the local demo. Open that page in Chrome or Edge for the meeting-note AI. First setup can take several minutes.

Audio was tested on Windows x64. The libraries support Intel and Apple Silicon Macs, but this demo still needs a teammate's Mac execution check. Windows on ARM is unverified.

Choose your recording

  1. Once the launcher is running, use the page it opens: http://127.0.0.1:4176/demo-1/. This address runs on your own computer. If it opens in another browser, copy it into Chrome or Edge.
  2. Expand Start from a recording. Look for Local audio companion connected, then choose an English MP3, WAV, M4A, OGG, or FLAC. Limits: 10 minutes and 80 MB.
  3. Set the number of speakers if you know it. Start with Whisper Base · faster, then click Transcribe & separate speakers. First use downloads roughly 200 MB of audio models. Small uses a larger model and takes longer. The progress display includes an estimated time remaining in minutes and seconds; it adjusts as processing advances.
  4. Review names, roles, text, and speaker assignments. Click a timestamp to listen. Introductions such as “My name is Maya and I'm the general contractor” may produce name suggestions; you can also enter names manually.
  5. Click Use reviewed transcript for notes, then Load AI & generate notes. The first Qwen download is roughly 1 GB. Loading and note generation run in sequence automatically. Interrupted downloads retry; if they still fail, check your connection and use Retry AI model download.
  6. Correct the notes and export before closing or refreshing. Use Export speaker transcript .json to save the transcript and Export notes to save the notes. Stop the companion with Ctrl+C in its terminal, on either platform.

Speaker labels and transcribed words can be wrong, especially with noise, short turns, or overlapping voices. Introductions suggest names; they do not verify identity. Audio uses the CPU. Note generation requires WebGPU and sufficient GPU memory in a compatible browser.

Share a transcript with your team

Export the speaker transcript as JSON from the local demo. A teammate can open the hosted Demo 1 page, expand Start from a recording, and click Import speaker transcript .json. They can review it and generate notes without installing the audio companion.

If something does not open

“Could not open requirements file” or “complete audio companion folder is missing”: close the launcher and extract the whole ZIP first. On Windows, right-click the ZIP → Extract All. Open the resulting capstone-grp2-main folder, then demo-1. The launcher and local-audio folder must stay together. Opening the launcher inside a ZIP can copy only that file to a temporary folder. Reinstalling Python will not fix missing project files.

If the page still says audio needs the local companion, check that you opened the 127.0.0.1:4176 address and that the launcher is still running. The GitHub website provides the download; it cannot automatically launch a program on your computer.

If setup fails, read the terminal's error message and check Python 3.12 and internet access. On Windows a missing Visual C++ runtime may need the official Microsoft runtime. If port 4176 is already in use, stop an older demo launcher before starting another. Split longer recordings into shorter clips.

Models stay in demo-1/local-audio/.models. Temporary audio copies are deleted after processing; your original file is untouched. A forced shutdown can leave temporary files. The latest transcript stays in the local service's memory until it stops, and notes are not saved automatically. Export before closing.
