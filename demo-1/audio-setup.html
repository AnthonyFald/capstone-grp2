Record once. Process locally.

The audio companion runs on your computer and opens the same Demo 1 page. Whisper transcribes the recording; speaker models group voices across it. Review names, roles, and wording, then generate meeting notes.

No paid API, key, or AI account. Setup downloads free packages and models. Recordings are processed on your CPU and are not sent to a cloud inference service.

One-time setup

  1. Get the complete capstone-grp2 project folder, including demo-1/local-audio. Extract the ZIP first.
  2. Install Python 3.12. On Windows, enable “Add Python to PATH.”
  3. Windows: double-click demo-1/Start Audio Demo.cmd.
    Mac: open Terminal in the project folder and run bash "demo-1/Start Audio Demo.command".
  4. Wait for the free package installation. The launcher opens the local demo. Keep its terminal open while processing.

Audio supports 64-bit Windows PCs and Intel or Apple Silicon Macs through the selected libraries. Windows on ARM is not verified. This build was tested on Windows; Mac installation still needs a teammate's check. A GPU is not required for audio. Browser note generation needs Chrome or Edge with WebGPU.

Use the demo

  1. Expand Start from a recording. Pick an English MP3, WAV, M4A, OGG or FLAC file, up to 10 minutes and 80 MB.
  2. If you know the number of speakers, enter it. For introductions, use “My name is Maya and I'm the general contractor.” Let everyone speak separately for a few seconds.
  3. Click Transcribe & separate speakers. The first Base run downloads roughly 200 MB of audio models. Small improves transcription at the cost of a larger download and slower processing.
  4. Check name suggestions, listen to turns using their timestamps, edit misheard words, and correct any wrong speaker assignments.
  5. Click Use reviewed transcript for notes, load the free Qwen model, and generate notes. Check decisions, responsibilities, deadlines, and open questions before exporting.

Speaker labels are estimates, particularly with noise, short turns, or overlapping voices. Intro matching recognizes a few explicit wording patterns; it does not verify identity or infer unstated roles. Unnamed speakers are fine.

Use the GitHub website too

Export the speaker transcript as JSON from the local demo. On the hosted Demo 1 tab, expand Start from a recording and import it. This also lets teammates review it without installing the audio companion. The website cannot run the Python audio companion by itself.

Storage and troubleshooting

Models stay in demo-1/local-audio/.models. Temporary audio copies are deleted after processing; your original file is untouched. The latest transcript remains in the local service's memory until it stops. Export before closing. Stop the service with Ctrl+C.

If setup fails, confirm Python 3.12 and internet access. On Windows a missing Visual C++ runtime may need the official Microsoft runtime. If port 4176 is already used, stop an older demo window or run python local-audio/server.py --port 4177 using the installed virtual environment. Long recordings should be split into shorter clips. Models can mishear speech or invent text in noise; human review remains part of this demo.
