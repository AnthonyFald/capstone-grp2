EVERGREEN MEETING DEMO

WINDOWS
1. Extract the entire ZIP first (right-click > Extract All).
2. Open the extracted Evergreen Meeting Demo folder.
3. Double-click Evergreen Meeting Demo.exe.
   Keep the _internal folder beside the app.

APPLE SILICON MAC
1. Double-click the Mac ZIP to extract it.
2. Move Evergreen Meeting Demo.app into Applications, then open it.
   This download is for M-series Macs, not Intel Macs.

No Python installation or terminal commands are required.
Return to your existing Demo 1 browser tab; it connects automatically.
The app opens a page only when you click Open demo, using your default browser.
Keep its small window open while using the demo. Quit it when finished.

Choose your recording in Start from a recording. First use downloads the
free audio models. Review the transcript, generate notes, and export them.
Recordings and inference stay on this computer. No paid AI account or key.
Note generation needs Chrome or Edge with WebGPU. Model setup needs internet.

DEMO 2 - DAILY REPORTS
The sidebar now opens Demo 2 locally. Choose reports, run a browser model,
review the original evidence, and export your findings and evaluation data.
The 4B option uses less memory; the thorough 9B option performs more review.
Both support Apple silicon through WebGPU. Only RTX 5080 performance has
been measured for this project. Model quality still needs human review.
Native 9B reasoning and experimental 27B require the separate Ollama/Node
companion described in Demo 2's Windows & Apple silicon setup link.

This is an unsigned student demo. Windows or macOS may ask for approval on
first opening. Download only from the project's own GitHub release. A Mac
may require System Settings > Privacy & Security > Open Anyway for this app.
Do not disable system security. On a managed computer, ask its administrator.

Export your transcript and notes before quitting or refreshing the browser.
If something fails, click Show support log in the launcher.
A browser may ask for local network access to contact this computer only.
The companion does not discover or connect to other devices on your network.
If the browser blocks that connection, Open demo provides a local page.
