What this demo tests

Can AI accurately capture construction meeting decisions, assigned responsibilities, deadlines, and unresolved questions?

This is Demo 1 from Team 2’s thesis. It tests documentation quality as a step toward reducing avoidable RFIs. It does not measure or establish a 30% reduction in RFIs.

Two honest modes

Local AI: a real Qwen 2.5 1.5B language model, run by WebLLM on your computer. Downloads are free; there are no hosted inference calls, accounts, or API keys.

Basic extraction: deterministic text patterns. Useful as a baseline or technical fallback, but it cannot support an AI performance claim.

Run the experiment

  1. Have a teammate write notes from a sample without seeing the references. Record their time.
  2. Generate AI notes, then review and correct them. Record review time.
  3. Compare with the reference checklist. A reviewer must judge completeness and correctness, including owners and dates.
  4. Export the results. Repeat with new transcripts before drawing conclusions.

The reference checklist is synthetic and was authored alongside the demo with Codex assistance. Have the team verify it before using it as ground truth. None of these records comes from the actual construction team.

Local AI needs WebGPU and a localhost or HTTPS address. If you opened index.html directly, run Start Demo.cmd for local AI. Closing or reloading the page clears the notes; export before leaving.
