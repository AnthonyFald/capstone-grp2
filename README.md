# Evergreen — INFO 492 Team 2

A dependency-free documentation website based on the team's supplied thesis and presentation. All site files are in `dist/`. Open `dist/index.html` directly or serve the folder with any static web server. No install or build step is required.

## Editing

- `dist/index.html`: project content, navigation, experiments, sources, and team
- `dist/styles.css`: desktop and responsive layouts
- `dist/app.js`: experiment expansion and active navigation
- `dist/assets/`: project rendering extracted from the supplied slides
- `dist/documents/`: original supplied project files

The proposal is not a report of completed experiments. Synthetic scenarios and unsupported RFI assumptions are labeled. Cole Wieland's contribution statement was absent from the supplied materials and remains marked as missing.
