# Demo 2 — Daily construction report review

Use daily site updates from supervisors, superintendents and trades: work completed, inspections, problems, instructions, deliveries and next steps. Each spreadsheet row or JSON object is one report from one author/trade/date. Start with **Use sample reports** or download the [sample CSV](data/sample-daily-reports.csv) / [sample JSON](data/sample-daily-reports.json), then upload it to test the workflow. The [upload guide](docs/upload-guide.md) describes required columns and limits. PDF, Word, photos and audio are not supported imports.

Select **Analyze reports**, check the findings against their dated source timeline, choose Keep/Correct/Reject and download. Sources and corrections are preserved separately from original predictions. Advanced model/device settings and research tools are collapsed; normal review does not require scoring, timers or batch experiments.

The source-based pipeline constructs an exact sentence inventory and asks the local model to select/group evidence, reconcile later updates, and check omitted concerns. Focused checks inspect remaining tasks, historical work/delivery changes and opposing inspection/release accounts, followed by materiality verification. The app renders original text and its report author/date, without generating causes, impacts, owners or deadlines. Type, status, relevance and grouping remain fallible model interpretations. A valid quotation does not prove its interpretation. Source validation is idempotent for short identifiers, rejects nonexistent or stale pointers, and uses a bounded source-based adjudication for conflicting exact duplicates. An unresolved conflict still rejects the result.

The installed **Qwen 3.5 27B** model is preferred for quality; Qwen 3.5 9B and browser 9B/4B are lower-memory alternatives under Advanced settings. Native models use Ollama plus `node scripts/serve-local-ai.mjs` on loopback. All report processing stays on device. Initial model/library downloads need internet. See [Windows and Apple silicon setup](docs/local-setup.md). Apple silicon runtime compatibility is retained; measured inference uses the RTX 5080 only.

Included A/B and additional D cases informed development. C/E are routine-work controls. F was authored separately with references withheld from the implementing agent until a recorded freeze and completed evaluation. Its v15 attempt was canceled before completed predictions; the next freeze precedes the first completed F run. Case authors inherited project context, so this is agent-assisted evaluation requiring independent human validation. Scoring uses original predictions, counts partials as misses, and classifies unsupported outputs and duplicates separately. No human productivity observations were invented. See [results](docs/results.md), [protocol](docs/protocol.md), [data review](docs/data-review.md) and [collection guide](docs/collection-guide.md).

Checks: `node --test demo-2/tests/*.test.cjs demo-1/tests/*.test.cjs tests/*.test.cjs`. Source inventory, pointer validity, short-citation idempotence, audit edits, stale-state guards, exports and local request isolation have regression coverage. Model quality is assessed with real retained inference outputs, not unit-test mocks.

Source/runtime: [WebLLM registry](https://github.com/mlc-ai/web-llm/blob/v0.2.85/src/config.ts), [Ollama structured outputs](https://docs.ollama.com/capabilities/structured-outputs), [Qwen model settings](https://huggingface.co/Qwen/Qwen3.5-27B). Exports retain the actual model configuration, seed, raw responses and per-pass settings/timings. Failed, canceled and staged development attempts remain distinguishable from fresh completed evaluations; staged execution is excluded from continuous latency summaries.

The current browser 4B single-pass control ran successfully on the RTX 5080 but returned four routine-work false alerts. It remains an explicitly experimental memory fallback, not a recommended accuracy profile. Native 27B returned zero alerts on both routine controls. Apple silicon compatibility is retained through the runtimes; no Mac inference quality or timing is claimed.
