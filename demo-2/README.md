# Demo 2 — Assisted daily report analysis

Open `demo-2/` on the project website or run `node scripts/serve.mjs` from the repository root and open its local URL. Browser AI needs current Chrome/Edge with WebGPU and sufficient GPU/unified memory. No paid API, account or Python dependency is needed. The native 9B quality and optional 27B models use Ollama plus `node scripts/serve-local-ai.mjs`; see [Windows and Apple silicon setup](docs/local-setup.md). The keyword baseline needs no GPU.

Choose the original pilot, transfer set or negative control. Analyze, inspect the linked original reports, record accept/correct/reject decisions, and export JSON or CSV. Import the provided CSV or your own JSON using the same field names. Imported data never receives the bundled answer key. Only recognized source fields are sent to inference.

Options: lower-memory Qwen 3 4B, browser Qwen 3.5 9B in one-pass or thorough mode, native Qwen 3.5 9B with thorough reasoning, and experimental higher-capacity native Qwen 3.5 27B reasoning in one full-source pass. Thorough mode reviews readiness/prerequisites, technical decisions/formal communication, progress/closeout, and causes/trade coordination separately. Each subject receives a verification pass against the complete original reports; there is no final compression into a shorter summary. The 27B model is larger; the two 9B browser modes differ only in inference work. The RTX 5080's 16 GB plus about 95 GiB system RAM is the test environment. The 27B model partially uses system RAM and takes longer. Apple silicon browser/local-runtime support is retained, but no Mac benchmark was run. Download/setup latency is separate from processing. Compare actual issue coverage and false claims before choosing a model.

The model selects report and field references. Owner/deadline suggestions are left unstated and flagged unless tied to an exact source action and its assignment metadata; raw responses preserve the original suggestion. The application retrieves original source text rather than trusting generated quotations. A valid citation does not establish that its interpretation is right. Findings need human review; this app cannot authorize work or close an RFI. Processing stays local, but initial model/library downloads and website access need internet. Full offline packaging is not claimed.

“Run 3 measured trials” runs serially and retains raw outputs, per-pass timings, inputs/hash, model/prompt metadata and original findings in memory. Export all trials before closing. Corrections do not overwrite validated original findings or raw model responses. Open scoring only after blind review; complete every judgment to calculate metrics. The human comparison form requires measured values.

See [protocol](docs/protocol.md), [data review](docs/data-review.md), [results](docs/results.md) and [human data collection](docs/collection-guide.md). These research files support later documents/slides and independent human evaluation. Original team documents and presentations have not been rewritten.

Checks: `node --test demo-2/tests/*.test.cjs demo-1/tests/*.test.cjs tests/*.test.cjs`.

Regenerate controls: `node demo-2/scripts/generate-controls.cjs`. Import the original workbook with `python scripts/import-daily-reports.py "path/to/Simulated Daily Reports CSV.xlsx"` and openpyxl. This development import is separate from the browser workflow. Model source: [WebLLM 0.2.85 registry](https://github.com/mlc-ai/web-llm/blob/v0.2.85/src/config.ts); runtime: [WebLLM documentation](https://webllm.mlc.ai/docs/user/basic_usage.html).
